EXIM Elite Contact Exporter v1.7.9

1. Open Terminal in this folder.
2. Run: npm install
3. Run: npm run agent:login
4. Sign in to Gemini in the opened Chrome window.
5. Wait until Terminal says "Gemini login confirmed" and Chrome closes itself.
6. Only after the login command exits, run: npm run agent
7. Leave that Terminal window running.
8. Open chrome://extensions and enable Developer mode.
9. Click Load unpacked and select this folder.
10. Refresh the EXIM Elite report, apply filters, and click Capture All.

Badge:
AI = working
IN = Gemini login needed
OK = complete
!  = failed

The popup may close when you switch tabs. The local agent continues in the
background; reopen the extension popup to see progress and export Excel.

After the one-time visible npm run agent:login step, npm run agent opens a
visible Gemini page so you can inspect the prompt. Chrome opens immediately
when manual CAPTCHA/login action is needed. If the agent is stopped, the last
saved partial rows remain exportable and the badge changes to OK.

Mac and Windows use the same npm commands. The agent handles Command+V on
macOS and Control+V on Windows/Linux internally.

Every contact lookup uses the report's captured hover Google query URL first.
The agent searches Google in 6 visible tabs, waits for up to 3
organic website candidates, and sends every ready 15-result batch to Gemini.
Gemini picks the first valid non-social website, then uses deepsearch websearch
scraping on that selected URL/domain for phone/email. Workers wait when free RAM is low, cap browser cache,
and prune old job files on Mac and Windows. Waiting rows continue automatically.
To tune it, run the agent with GEMINI_PARALLELISM=1..30 and keep
GEMINI_PARALLELISM_AUTO=true for the smooth safe limit.

No Gemini API key is required. Do not put account passwords in this folder.
